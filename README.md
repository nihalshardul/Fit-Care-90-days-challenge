# Fit-Care-90-days-challenge
90-Day Progress for Home Workout, Diet &amp; Nutrition, Water Tracker, Posture Correction, Sleep Tracker and Hair Care.

Features:
- Embedded body transformation tracker (weight/waist, food, water, posture, sleep, hair care, checkboxes)
- Home workout Mon–Sun + YouTube tutorial search links
- Native daily notification reminders (water, posture, sleep) with default times 10:30, 14:00, 22:30
- Reminder times can be changed in app Settings and saved to Android alarms
- Local device/browser storage; use Export data for backup

Notifications:
- Android 13+ notification permission - required .
- Android battery optimization/device vendor policies reminders delay.
- Default reminders reschedule after reboot.
- No App data cloud sync.
  
Health note: fitness targets are starting estimates, not medical advice. For a prominent/rigid hump or new symptoms, seek clinician assessment.
